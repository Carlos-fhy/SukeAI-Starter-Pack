# 对话、编程与效率工具

## 对话类工具

对话类工具适合快速提问、头脑风暴、解释概念和改写文本。使用时最好明确说明身份和背景、具体目标、输出格式、长度以及不能修改的内容。

## 编程类工具

- **GitHub Copilot**：适合在编辑器中补全、解释和辅助开发。
- **Cursor**：以 AI 编辑器为核心，适合项目级代码修改。
- **Trae**：适合中文用户进行代码问答和项目开发。
- **通义灵码**：适合中文开发环境中的代码补全和问答。
- **CodeGeeX**：支持代码生成、补全和解释。

使用 AI 改代码时，应当先让它解释修改方案，再限制修改范围，并通过测试、代码审查和版本控制确认结果。

## 文档、阅读与效率工具

具备文件上传或长文本处理能力的工具可以用于章节摘要、关键概念提取、复习提纲、术语表和自测题生成。

不要直接把未公开的实验数据、个人信息、学校内部文件或他人作品上传到不明确的平台。
