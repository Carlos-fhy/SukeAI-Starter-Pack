# Agent 概念与常见工具

## Agent 是什么

普通聊天通常是“提问—回答”，而 Agent 可以在目标约束下分解任务、调用工具、读取文件、执行代码并根据结果继续行动。

对话模型负责思考和生成内容，Agent 负责把思考连接到工具和实际行动。它并不是完全自动化的“万能程序”，涉及删除文件、发送消息、修改代码和提交数据时，应保留人工确认。

## 常见 Agent 工具

| 工具 | 主要用途 |
| --- | --- |
| **ChatGPT / Claude / Gemini 的任务或项目功能** | 资料分析、持续对话和多步骤任务 |
| **GitHub Copilot Agent** | 在代码仓库中分析、修改和验证代码 |
| **Cursor Agent** | 在编辑器中进行项目级开发 |
| **Claude Code** | 通过终端辅助理解和修改代码 |
| **Dify** | 可视化搭建工作流和知识库应用 |
| **Coze / 扣子** | 搭建个人或团队智能体应用 |
| **n8n** | 将 AI 与网页、表格、数据库和第三方服务连接起来 |

## 从对话到 Agent

1. 先用普通对话模型解决一个小问题；
2. 把任务拆成输入、处理步骤和预期输出；
3. 明确 Agent 可以使用的文件、工具和权限；
4. 先在副本或测试项目中运行；
5. 检查每一步的输出和日志；
6. 确认无误后，再应用到正式项目。
