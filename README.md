# 大学生 AI 开荒指南

> 面向所有大学生的 AI 使用与驾驭指南。

本项目不以某个专业为中心，而是按照 AI 的学习阶段、实际任务、能力边界和工具组合，帮助大学生从“会使用”逐步走向“会驾驭”。

## 项目目录

- `docs/`：网站展示的文档内容；
- `examples/`：提示词、数据分析、写作、代码和 Agent 示例；
- `archives/`：历史内容和获得授权的资料；
- `scripts/`：文档检查与构建辅助脚本；
- `code/`：可运行的代码示例。

网站使用 Astro + Starlight 构建，开发时运行 `npm install` 安装依赖，再运行 `npm run dev` 预览。
