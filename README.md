## 一、开始之前：网络与基础准备

### 1. 科学上网是什么

“科学上网”通常是指通过网络代理工具访问特定网络服务。对于 AI 学习来说，部分海外模型、开发文档和开源项目可能需要更稳定或不同的网络连接。

本指南只做基础科普，不提供绕过网络管理、规避监管或获取未经授权服务的教程。使用网络代理时，请遵守国家法律法规、学校网络管理规定以及服务提供商的使用条款。

### 2. 常见客户端推荐

以下软件主要用于管理代理订阅和网络规则。它们本身通常不提供网络线路，使用前需要自行确认服务来源是否正规、可靠。

| 软件 | 适合平台 | 简要说明 |
| --- | --- | --- |
| **Clash Verge Rev** | Windows、macOS、Linux | 界面较友好，适合桌面端入门用户 |
| **Mihomo Party** | Windows、macOS、Linux | 基于 Mihomo 内核，功能较完整 |
| **FlClash** | Windows、macOS、Linux、Android | 跨平台，适合希望多端使用的用户 |
| **sing-box** | Windows、macOS、Linux、Android、iOS | 灵活、可配置性强，更适合有一定基础的用户 |
| **Shadowrocket（小火箭）** | iPhone、iPad | 苹果用户常见的代理客户端，操作相对简单 |

#### 苹果用户：小火箭的使用提醒

小火箭（Shadowrocket）是苹果用户中较常见的选择，但使用前需要注意：

- 它通常需要通过**符合所在地区规则的 App Store 账号**获取，部分用户可能需要美区 Apple 账号，具体以 App Store 实际上架情况为准。
- 不要购买或使用来路不明的 Apple 账号，避免账号被找回、锁定或产生支付纠纷。
- 小火箭只是客户端，本身不提供网络线路；订阅服务需要另行选择，并确认来源可靠。
- App Store 账号切换、应用购买和订阅配置可能带来额外的操作成本，因此不一定适合所有用户。

选择时可以优先考虑：

1. 是否支持自己的操作系统；
2. 项目是否仍在维护；
3. 配置文件来源是否可信；
4. 是否有清晰的隐私政策和售后支持。

### 3. 使用时的注意事项

- 不要下载来路不明的安装包，也不要随意导入陌生配置文件。
- 不要在代理服务中输入身份证号、银行卡号、密码等敏感信息。
- 学校网络、实验室网络和公共 Wi-Fi 可能有额外管理规定，使用前请先了解相关要求。
- 网络连接不稳定时，优先检查本地网络、DNS、系统代理和软件日志，不要反复更换不可信的配置。

## 二、国内 AI 模型入门

### 1. 什么是大语言模型

大语言模型（Large Language Model，LLM）是一类能够理解和生成自然语言的 AI 模型。它可以用于问答、总结、翻译、写作、编程和资料整理，但并不等于搜索引擎，也不能保证每次回答都正确。

使用模型时，应当把它当作“能力较强的助手”，而不是绝对可靠的权威来源。涉及课程作业、实验数据、法律法规和医学信息时，需要自行核验。

### 2. 常见国内模型与平台

国内平台通常可以直接使用中文服务，注册和访问门槛相对较低。常见选择包括：

- **DeepSeek**：适合通用问答、逻辑分析和编程辅助。
- **通义千问**：适合中文写作、知识问答和办公场景。
- **豆包**：适合日常对话、内容创作和多模态体验。
- **文心一言**：适合中文问答、写作和搜索类场景。
- **智谱清言 / GLM**：适合中文对话、学习辅助和开发者调用。
- **Kimi**：适合长文本阅读、资料整理和文档总结。

模型和平台会持续更新，具体能力、免费额度、联网功能和 API 价格以官方页面为准。

### 3. 如何选择模型

可以根据任务类型选择：

| 任务 | 优先考虑的能力 |
| --- | --- |
| 课程概念解释 | 中文理解、循序渐进、举例能力 |
| 论文或长文总结 | 上下文长度、引用定位、结构化输出 |
| 编程学习 | 代码生成、调试、解释和多轮对话 |
| 图片或表格处理 | 多模态输入、文件解析、结果导出 |
| 复杂推理 | 推理能力、思路检查、结果可验证性 |

建议不要只看“哪个模型最强”，而是准备两个或三个常用模型，根据任务进行交叉验证。

## 三、AI 软件与工具

### 1. 对话类工具

对话类工具适合快速提问、头脑风暴、解释概念和改写文本。使用时最好明确说明：

- 你的身份和背景；
- 想解决的具体问题；
- 输出格式和长度；
- 是否需要例子、步骤或对比；
- 哪些内容不能被修改。

### 2. 编程类工具

编程辅助工具可以帮助解释代码、定位报错、生成测试和完善文档。常见工具包括：

- **GitHub Copilot**：适合在编辑器中补全代码、解释代码和辅助开发。
- **Cursor**：以 AI 编辑器为核心，适合项目级代码修改。
- **Trae**：适合中文用户进行代码问答和项目开发。
- **通义灵码**：适合中文开发环境中的代码补全和问答。
- **CodeGeeX**：支持代码生成、补全和解释。

使用 AI 改代码时，应当让它先解释修改方案，再限制修改范围，并通过测试、代码审查和版本控制确认结果。

### 3. 文档、阅读与效率工具

对于 PDF、网页和课程资料，可以使用具备文件上传或长文本处理能力的工具进行：

- 章节摘要；
- 关键概念提取；
- 复习提纲生成；
- 术语表整理；
- 根据资料生成自测题。

不要直接把未公开的实验数据、个人信息、学校内部文件或他人作品上传到不明确的平台。

## 四、Agent 工具入门

### 1. Agent 是什么

普通聊天通常是“提问—回答”，而 Agent 可以在目标约束下分解任务、调用工具、读取文件、执行代码并根据结果继续行动。

简单来说：

> 对话模型负责思考和生成内容，Agent 负责把思考连接到工具和实际行动。

Agent 并不是完全自动化的“万能程序”。它可能误解目标、执行错误操作或生成不可靠结果，因此涉及删除文件、发送消息、修改代码和提交数据时，应保留人工确认。

### 2. 常见 Agent 工具

| 工具 | 主要用途 |
| --- | --- |
| **ChatGPT / Claude / Gemini 的任务或项目功能** | 资料分析、持续对话和多步骤任务 |
| **GitHub Copilot Agent** | 在代码仓库中分析、修改和验证代码 |
| **Cursor Agent** | 在编辑器中进行项目级开发 |
| **Claude Code** | 通过终端辅助理解和修改代码 |
| **Dify** | 可视化搭建工作流和知识库应用 |
| **Coze / 扣子** | 搭建面向个人或团队的智能体应用 |
| **n8n** | 将 AI 与网页、表格、数据库和第三方服务连接起来 |

### 3. 从对话到 Agent 的使用流程

推荐按以下顺序学习：

1. 先用普通对话模型解决一个小问题；
2. 把任务拆成输入、处理步骤和预期输出；
3. 明确 Agent 可以使用的文件、工具和权限；
4. 先在副本或测试项目中运行；
5. 检查每一步的输出和日志；
6. 确认无误后，再应用到正式项目。

## 五、校园学习场景实践

后续可以围绕以下场景补充实际案例：

- 用 AI 制定课程复习计划；
- 将课堂笔记整理成知识框架；
- 根据教材生成练习题和错题解析；
- 辅助编程作业的调试与测试；
- 阅读论文并生成问题清单；
- 规划竞赛、科研或毕业设计任务；
- 自动整理资料、表格和项目文档。

## 六、提示词与工作流

一个实用的提示词通常包含：

```text
背景：我是一名……
目标：我希望完成……
材料：以下是相关资料……
限制：请不要……，请遵守……
输出：请按照……格式输出……
检查：请列出可能存在的不确定内容……
```

不要迷信复杂的“万能提示词”。清楚的背景、明确的目标、可验证的输出格式，通常比堆砌关键词更重要。

## 七、隐私、安全与学术规范

- 不上传密码、密钥、身份证号、联系方式和未公开数据。
- 不把 AI 生成内容直接当作事实，重要内容必须查证来源。
- 遵守课程要求和学术诚信规范，明确区分自己的工作与 AI 的辅助。
- 使用他人的论文、图片、代码和数据时，遵守版权和许可协议。
- 对 AI 生成的代码进行人工审查，特别关注依赖、权限、输入校验和数据安全。

## 八、进阶路线

可以按照下面的路线逐步学习：

1. **会提问**：掌握任务描述、上下文补充和结果校验；
2. **会比较**：了解不同模型的特点，学会交叉验证；
3. **会使用工具**：把 AI 用到阅读、写作、编程和资料整理中；
4. **会搭工作流**：使用 Dify、Coze 或 n8n 连接多个工具；
5. **会开发 Agent**：学习 API、函数调用、知识库和权限控制；
6. **会评估结果**：建立测试样例、日志和人工审核机制。
