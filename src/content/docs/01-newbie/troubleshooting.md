不用通读。找到与你遇到的情况最接近的一行，先做一个小检查。

| 卡在哪里 | 先检查 | 可以怎么继续 |
| --- | --- | --- |
| 打不开或登不上 | 是否为官方入口，网络是否正常，有没有明确报错 | 按官方提示重试或查看帮助；临时换一个能正常访问的平台 |
| 找不到教程里的按钮 | 网页与手机端是否不同，当前账户是否支持该功能 | 查官方帮助；用文字或浏览器搜索完成练习，也可以跳过暂时不支持的功能 |
| 附件上传失败 | 平台提示的格式、大小、页数限制，以及文件是否损坏或加密 | 使用有权提供的小段文字或完整小节；保留原文件，不上传到陌生中转站 |
| 上传成功却读错 | 有没有漏页、模糊文字、复杂表格或错误的行列对应 | 缩小到具体页或段落，先让它复述，再与原文核对；必要时手动录入关键内容 |
| 回答到一半停了 | 是篇幅过长，还是出现网络、额度或服务错误提示 | 长内容按小节生成；续写时指明接续位置，再检查重复与遗漏；其他情况按报错处理 |
| 提示额度不足 | 当前免费额度、重置时间及可用模式 | 等待恢复，或用仍可用的功能完成简化练习；不必为了通关付费 |
| 越聊越偏、旧条件混进来 | 对话是否混了多个不相关任务 | 同一任务先重申当前条件；无关任务新开对话，带上必要背景与材料 |
| 回答空泛、不合要求 | 是否缺目标、材料、例子或输出标准 | 指出一处具体不足，再补条件；参考[任务发布教程](../clear-prompt/) |
| 回答前后矛盾 | 它是否改变了前提，或者根本没有可靠依据 | 记录冲突点，回到原始资料核验；参考[答案核验教程](../verify-answer/) |

## 继续聊，还是重新开一局？

同一份复习卡的修改，通常可以继续聊；从复习卡换到另一门课的题目，可以新开对话并重新提供条件。不要默认它能读取另一个会话、你电脑里的文件，或没有发给它的教师要求。

对话很长时，可以先自己整理「当前目标、确定条件、待解决问题」，检查无误后带到新会话里。若让 AI 帮忙总结，也要检查有没有漏掉限制。

## 求助时，带上这些线索

向官方客服或社区求助，可以说明使用的平台与端、发生在哪一步、报错原文，以及自己试过什么。截图先遮住姓名、手机号、聊天内容、验证码和密钥。

**不要把密码或验证码发给声称能帮你修复账号的人。** 功能暂时不可用，可以换条路完成练习；账户和材料不必一起交出去。
