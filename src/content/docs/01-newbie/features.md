第一次对话之后，先别急着寻找更厉害的平台。看看输入框周围，你的搭档也许还有几招。

## 领取任务

找到常用功能，知道什么时候值得开启。不同平台的名称、入口、额度和支持范围会变化；没有某个按钮，也不影响继续学习。

| 功能 | 什么时候用 | 用完检查什么 |
| --- | --- | --- |
| 普通对话 | 解释概念、修改文字、整理你给出的材料 | 是否符合要求，事实是否可靠 |
| 联网搜索 | 查近期公告、寻找官方资料和原始出处 | 是否真的出现检索结果；来源、日期和适用范围是否对应 |
| 深度思考 / 推理 | 需要拆解条件、比较方案或分析较复杂的问题 | 前提有没有遗漏，推导和结果能否独立核对 |
| 上传附件 | 根据图片、文档或表格处理任务 | 是否读到正确文件，有没有漏页、漏行或识别错误 |
| 语音输入 / 对话 | 不方便打字，或想练习口头表达 | 人名、数字、专业词有没有被听错 |

:::tip[不用把技能全部点亮]
先看任务需要什么。修改一段自己写的文字，可以先用普通对话；查本校最新通知，应去学校官方渠道核对，需要时再用搜索帮助定位。
:::

## 看见按钮，不等于任务已经完成

- 开了搜索，仍要自己打开出处；AI 说「查过了」不是检索证据。
- 开了深度思考，仍可能得出错误答案；回答更长也不代表更可靠。
- 上传了文件，仍要检查它读到了什么。下一关的[材料教程](../materials/)会带你具体操作。
- 用语音提问后，先检查转写文字；公共场合也要注意周围的人能听见什么。

## 试着切换一次

1. 在普通对话中问：「用校园生活的例子解释什么是机会成本。」检查它是否解释清楚。
2. 换一个确实需要近期信息的问题，例如查找学校官网最近发布的一则公开讲座通知。
3. 如果平台提供搜索功能，启用后请它寻找官方通知，并列出标题、发布日期和链接；没有这个功能，就用浏览器搜索。
4. 自己打开学校原文，核对时间、地点和参加条件。找不到对应原文，就把结果记为「尚未核实」。

## 通关条件

- 能说出普通对话与联网搜索分别适合什么任务。
- 找到至少两个常用功能入口；缺少功能时知道可以换一种做法。
- 知道开启功能不等于答案已经通过检查。
