本阶段不要求编程基础，也不建议为了完成练习先付费。学完你应该能独立完成五个动作：**选一个平台开始用、把需求说清楚、判断回答能不能信、知道什么不能上传、知道学校的基本要求**。

联合国教科文组织《生成式人工智能教育与研究指南》强调以人为中心、隐私保护和学习者的自主性：AI 是学习辅助工具，不是责任的替代者（[UNESCO](https://www.unesco.org/en/articles/guidance-generative-ai-education-and-research)）。

## 通关任务

<div class="task-list">
  - [ ] 我能说出三个国内平台的官方入口，并选定一个固定使用
  - [ ] 我能发起、追问、重开，并找到历史对话
  - [ ] 我能用背景、目标、材料、输出格式描述任务
  - [ ] 我知道 AI 可能编造文献、数字和通知，并会回到原始资料核对
  - [ ] 我能分辨公开、需脱敏与不可外传的信息
  - [ ] 我知道作业、论文和科研任务要核对本校与任课教师的要求
</div>

> 最后一步实战：拿一门真正不懂的课，用四要素提问；从回答里挑一条可检查的事实，找到原始来源；再检查这次对话有没有用到不该上传的信息。三步都完成，这一阶段就通关了。
