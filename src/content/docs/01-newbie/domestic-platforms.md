## 常见国内模型与平台

- **DeepSeek**：适合通用问答、逻辑分析和编程辅助。
- **通义千问**：适合中文写作、知识问答和办公场景。
- **豆包**：适合日常对话、内容创作和多模态体验。
- **文心一言**：适合中文问答、写作和搜索类场景。
- **智谱清言 / GLM**：适合中文对话、学习辅助和开发者调用。
- **Kimi**：适合长文本阅读、资料整理和文档总结。

模型和平台会持续更新，具体能力、免费额度、联网功能和 API 价格以官方页面为准。

## 如何选择

不同任务适合不同的模型，具体方法见「模型选择」一节。
