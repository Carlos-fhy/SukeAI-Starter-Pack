这一页不用通读，也不用背。看文章或视频时碰到不认识的词，回到这里对一下；手机上可以直接用浏览器的页内查找（Ctrl+F 或长按标题搜索）。

## 一张表

| 术语 | 一句话解释 | 实际要注意什么 |
| --- | --- | --- |
| **大模型** | 从大量文本中学会预测下一个词，因此能接着你的话往下写 | 写得顺不等于写得对 |
| **参数** | 模型内部可以被调整的数值，规模常用「亿」「B」表示 | 数字大小和你的实际体验关系不大 |
| **训练 / 推理** | 训练是厂商用数据调整模型；推理是你提问后模型算出回答 | 你平时用的是推理，用一次算一次 |
| **Token** | 模型处理文字的最小单位，一个汉字通常一到两个 | 长文档、长对话会消耗更多它 |
| **上下文** | 这次对话里模型能看到的全部内容：你的问题、前面的回答、上传的材料 | 超出长度的部分会被丢掉，重要条件要重说 |
| **多模态** | 除文字外还能看图、听声音、读文档 | 你上传的图片也可能带姓名、地址等信息 |
| **幻觉** | 模型把不存在或错误的内容当成事实说出来 | 引文、数字、日期最容易被编出来 |
| **联网搜索** | 模型先检索网页再作答 | 检索到的网页本身也可能是错的 |
| **推理模型** | 回答前先写出较长的思考过程，适合数学、代码、逻辑题 | 慢一些，简单问题上不一定更好 |
| **Agent（智能体）** | 能自己拆步骤、调用工具的 AI 系统 | 让它动手之前，先看清它要动什么 |

## 两个常见的误会

**「参数多就更聪明。」** 参数只是规模指标之一。训练数据、后训练方法和产品设计都会影响结果，而且同一个模型在不同任务上的表现也不一样。

**「AI 说它联网查过了，那就查过了。」** 它可能真的检索了，也可能只说检索了。判断标准只有一个：来源能不能自己打开。

## 还不确定的词

大多数校园里听到的新词，都可以用「是什么 + 怎么用 + 有什么坑」三句话讲清。想快速搞懂一个词，可以直接问 AI：「用三句话解释 X，给一个大学生能遇到的例子，再说一个常见误解。」但记得把它的解释和教材、官方文档对一遍。
